TEMPLATE BUKU BARU
1. Duplikat folder _template dan ubah nama folder.
2. Edit book.json; id harus unik.
3. Masukkan cover.jpg.
4. Tambahkan file bab ke chapters/ dan daftarkan di array chapters.
5. Tambahkan path book.json ke BOOK_INDEX di app.js.
6. Set featured: true jika ingin menjadi pilihan unggulan.
